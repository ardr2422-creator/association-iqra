# Charte de marque Iqra compta

- `charte.html` / `charte-iqra.pdf` : la charte complète en 8 planches (nom,
  couleurs claires et sombres, typographie, composants, écrans, mouvement et ton).
- `nom-iqra-clair.svg`, `nom-iqra-sombre.svg` : le nom « Iqra compta », à utiliser
  à la place d'un logo.
- `palette.svg` : toutes les couleurs, en clair et en sombre.

**Dans Figma** : glissez les fichiers `.svg` sur la page ; ils deviennent des
calques modifiables (textes en Inter, aplats de couleur). Le PDF peut aussi être
glissé dans Figma : chaque planche devient un cadre.
